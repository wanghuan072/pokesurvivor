## JSON 发布开关

文件：`src/data/pokedex/pokemon.json`，每条记录必须有布尔字段 `hasDetailPage`。

```json
{
  "id": 25,
  "slug": "pikachu",
  "name": "Pikachu",
  "hasDetailPage": true
}
```

上例是字段片段，其余游戏数据保留。`true`：生成详情页、展示详情链接、纳入搜索与 sitemap。`false`：仅在名单展示数据，不出现详情链接，直接请求详情 URL 返回 404。图鉴、排行和配装中的伙伴链接均遵守开关。

首版开放：Bulbasaur、Charmander、Charizard、Squirtle、Pikachu、Psyduck、Gengar、Eevee、Gardevoir、Lucario，共 10 个。其余 956 个为 false。

后续发布：完善相应内容后把该记录设为 true，然后重新构建并发布；无需增加路由文件、搜索配置或 sitemap 条目。关闭页面同理需要重新构建。游戏数据导入按稳定 id 保留已有开关；新增 id 默认 false，不会自动发布。
