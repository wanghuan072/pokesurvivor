## 关键解释

波次每局抽选七个物种，候选池不等于保证生成；旧阶段会继续混入。Boss 各槽位尽量不重复，空池有 BST ≥580 的回退条件。模板 HP/伤害与实际战斗数值之间还存在物种、行为、时间、Spawner、合作模式等修正，页面不把模板冒充最终敌人属性。

任务页面展示 10/6 个模板，不声称知道用户当天的 3/2 个实际任务。任务日历使用 Europe/Madrid，完成与领取分开。宝箱赔率来自实际 world.js 分支；随机事件、盗宝者时点等用对应版本声明，不宣传固定必得。

伙伴计划为编辑建议，候选招式与源码池校验，条件由招式数据渲染。未提供未经实测的 DPS 排名。
